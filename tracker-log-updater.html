Frame Tracker Updater

Reads Member Check Lists from inspection PDFs and updates the INC 8 Frame Tracker in Smartsheet.

How to use: Paste your Smartsheet API token, then drop one or more inspection PDFs onto the drop zone. The tool will parse all Member Check List tables, match accepted items to tracker rows by Remarks reference, update quantities, and write all fields. Only rows with Acc/Rej = Accepted (or similar) and a valid Qty are processed. Unmatched rows are skipped and logged.
